# 脳内タブ

考えが別のことへ飛んだとき、思いついたことを一瞬で外に置いて、元の作業へ戻るためのアプリ。

## 使い方

1. ホームで「いま何してる？」に今の作業を入れる
2. 何か思いついたら「＋ 思いついた」→ 打つ → 「退避」（Enterでも可）
3. 「戻る」で元の作業へ
4. 迷子になったら「わたし、何してた？」
5. 退避したものは「あとで見る」でまとめて確認。タップで「完了」「削除」

データはこの端末のブラウザ内（localStorage）にだけ保存されます。
別の端末・別のブラウザとは共有されません。ブラウザのデータを消すと消えます。

## ファイルの役割

| ファイル | 担当 | こんなときに触る |
|---|---|---|
| `index.html` | 画面の骨組み・文言 | ボタンの文字や見出しを変えたい |
| `style.css` | 見た目（色・大きさ・余白） | 色や文字サイズを変えたい（色は一番上にまとめてある） |
| `js/storage.js` | データの保存・読み込み | 保存する項目を増やしたい、保存先を変えたい |
| `js/ui.js` | 画面の表示・切り替え | 一覧の見せ方や日時の表示形式を変えたい |
| `js/app.js` | ボタンを押した時の動き | 新しいボタンを足したい、動きを変えたい |

読み込み順は `storage.js → ui.js → app.js`（index.html の一番下）。

## データの形

```
CurrentTask（いまの作業・1件）
  id, text, createdAt

BrainTab（退避した思いつき・複数）
  id, text, createdAt, completed
```

localStorage のキー名：`noutab.currentTask` / `noutab.brainTabs`

## 動かし方

- パソコン：`index.html` をブラウザで開くだけ
- 公開：このフォルダごと GitHub に置いて Vercel にデプロイ（ビルド設定は不要）
- スマホ：公開したURLを開いて「ホーム画面に追加」するとアプリのように使える
