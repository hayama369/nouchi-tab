# 脳内タブ

考えが別のことへ飛んだとき、思いついたことを一瞬で外に置いて、元の作業へ戻るためのアプリ。
ホームには黒猫のハルがいる。

## 使い方

1. ホームの一番上「思いついた？」に、そのまま打つ
   - カテゴリのボタン（やること／かうもの／かんがえること／保留）を押すと、そのカテゴリを付けて一発で退避
   - 「退避」かEnterなら、カテゴリなしで退避（あとで付けられる）
   - 退避するとハルが受け取って鳴く。5秒以内なら「取り消し」で戻せる
   - カテゴリボタンの名前は `js/app.js` の一番上 `QUICK_CATS` で変えられる
   - 「声で入れる」「画像」は使いたいときだけ
2. その下に小さく「いま何してる？」。今の作業を入れておく（未登録のあいだ、ハルは寝てる）
3. 迷子になったら「わたし、何してた？」
4. 「あとで見る」で一覧。検索・絞り込み（今日／カテゴリ／未分類）ができる
   - 項目を押すと詳細：カテゴリ付け、画像、関連づけ、完了、削除（2回押し）
5. 「ふりかえり」で、今日ひらいたタブ／終わった作業／よく出る言葉／思いつきやすい時間／カテゴリ別
6. 作業を始めて45分たつと、ホームで「まだやってる？」と一度だけ聞く（通知は出さない）
7. ハルを触ると鳴く
8. 「ふりかえり」の一番下で合言葉を入れると、Mac と iPhone などで同期できる
   - 置き場所は「うちのこと」のサーバー（https://uchinokoto.vercel.app/api/sync）を借りている。合言葉の頭に noutab: を付けて送るので混ざらない
   - 同期するもの：いまの作業・あとで見る・終わった作業・描く・思いつきの画像
9. 「描く」で絵を描いた時間をはかる
   - 目安（10・25・30・60分）を過ぎると「休憩しろ」と出て、ぽろんと音が鳴る。止めるまでは数え続ける
   - 音は「休憩の音：オン／オフ」で切り替え（端末ごと）。Apple Musicなどの音楽は止めない（鳴る瞬間だけ少し小さくなる）。そのかわりマナーモード中は鳴らないことがある。アプリを開いていないときは鳴らせない
   - 1000時間 → 3000 → 5000 → 10000時間チャレンジ。前のアプリの時間は「これまでの時間」に手で入れる
   - 描いた日は月ごとのカレンダー（‹ › で月をめくる）。マスに日付とその日の時間、色が濃いほど長く描いた日
   - 下にその月の「描いた日」「合計」「いちばん続いた日数」。日を押すとその日の記録が出る
   - 連続日数、ハルのひとこと。はかり忘れた分は手で足せる
10. 「ふりかえり」の一番下で「アイコンに数字を出す」をオンにすると、ホーム画面のアイコンに「あとで見る」の未完了の数が出る
   - iPhoneはホーム画面に追加したアプリからだけ。通知の許可が必要（通知は送らない）
   - 設定 → 通知 → 脳内タブ で「バナー」「サウンド」をオフ、「バッジ」だけオンにすれば数字だけ出る

データはこの端末のブラウザ内にだけ保存されます（文字は localStorage、画像は IndexedDB）。
別の端末・別のブラウザとは共有されません。ブラウザのデータを消すと消えます。

## ウィジェット代わりの使い方（iPhone）

URLの最後に `#capture` を付けて開くと、いきなり「思いついた？」の欄にカーソルが入ります。
`#draw` を付けると、いきなり「描く」が開きます。
例：`https://（あなたのURL）/#capture`

「ショートカット」アプリで「URLを開く」にこのURLを入れたショートカットを作り、
ホーム画面にショートカットのウィジェットを置けば、ワンタップで退避できます。
（Androidはアプリのアイコンを長押しすると「思いついた」が出ます）

## ファイルの役割

| ファイル | 担当 | こんなときに触る |
|---|---|---|
| `index.html` | 画面の骨組み・文言 | ボタンの文字や見出しを変えたい |
| `style.css` | 見た目（色・大きさ・余白・ハルの動き） | 色や文字サイズを変えたい（色は一番上にまとめてある） |
| `js/storage.js` | 文字データの保存・読み込み | 保存する項目を増やしたい |
| `js/images.js` | 画像の保存（縮小してから保存） | 画像の大きさ・画質を変えたい |
| `js/haru.js` | ハルの形と、いつ鳴く／跳ねるか | ハルの見た目や鳴き声を変えたい |
| `js/voice.js` | 音声入力 | 音声入力の動きを変えたい |
| `js/analysis.js` | ふりかえりの集計 | 「よく出る言葉」から外す言葉を足したい |
| `js/ui.js` | 画面切り替え・ホーム・退避したときのハル・迷子救済 | ホームまわりの表示を変えたい |
| `js/ui-later.js` | 「あとで見る」一覧と詳細の表示 | 一覧や詳細の見せ方を変えたい |
| `js/ui-review.js` | 「ふりかえり」の表示 | グラフや履歴の見せ方を変えたい |
| `js/ui-draw.js` | 「描く」画面（時間をはかる・休憩の音・チャレンジ・月のカレンダー・ハルのひとこと） | 目安の時間や目標、ハルのセリフ、休憩の音を変えたい（chime） |
| `js/sync.js` | ほかの端末との同期（合言葉） | 同期の間隔や、同期するものを変えたい |
| `js/badge.js` | アイコンの数字（バッジ） | 数える対象を変えたい |
| `js/app.js` | ボタンを押した時の動き・設定 | 新しいボタンを足したい、カテゴリボタンの名前（QUICK_CATS）や「まだやってる？」の時間を変えたい |
| `manifest.json` / `icons/` | ホーム画面に追加したときの名前とアイコン | アイコンを変えたい |

読み込み順は index.html の一番下に書いてあります（保存 → 部品 → 表示 → 操作）。

## データの形

```
CurrentTask（いまの作業・1件）
  id, text, createdAt, checkedAt

BrainTab（退避した思いつき・複数）
  id, text, createdAt, completed, completedAt, category, imageId, links

TaskHistory（終わった作業）
  id, text, startedAt, finishedAt
```

localStorage のキー名：`noutab.currentTask` / `noutab.brainTabs` / `noutab.taskHistory`
画像：IndexedDB の `noutab` → `images`

## 動かし方

- パソコン：`index.html` をブラウザで開くだけ
- 公開：このフォルダの中身を GitHub に置いて Vercel にデプロイ（ビルド設定は不要）
- 更新：GitHub のファイルを差し替えると Vercel が自動で更新する
